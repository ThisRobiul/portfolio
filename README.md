## This website

This portfolio is a static website using **HTML, CSS and JavaScript**. It is configured for GitHub Pages and includes local assets (portrait, icons and fonts).

### File structure

```text
portfolio/
├── index.html
├── styles.css
├── script.js
├── .nojekyll
└── assets/
    ├── robiul-portrait.jpg
    ├── favicon.svg
    └── fonts and license files
```

### Run locally

Open `index.html` in a browser. For the most reliable local preview, use a simple local static server.

### Publish with GitHub Pages

1. Upload the listed website files and `assets/` directory to the repository root.
2. Open **Settings → Pages**.
3. Set **Deploy from a branch → main → /(root)** and save.
4. Check the **Actions** tab for a successful Pages deployment.
5. Open the published website and verify portrait, styles, menu, links and mobile layout.

**Expected GitHub Pages address:** https://thisrobiul.github.io/portfolio/ (available only after a successful deployment).
